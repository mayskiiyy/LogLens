# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in LogLens, please report it privately:

- **Email**: `security@loglens.dev` (or open a private Security Advisory on GitHub).
- Do not create a public issue.
- Please include steps to reproduce, affected deployment mode (Desktop or Self-Hosted), and impact details.

We aim to respond within 48 hours and coordinate a public release containing a patch within 14 days.
